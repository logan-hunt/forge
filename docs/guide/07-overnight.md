# Long-running work

Name a checkable outcome and work toward it through evidence-led iterations. Keep a decision trail for meaningful hypotheses, results and changed direction. Record the exact checkout and verification state so another agent can resume.

Use host completion notifications for delegates and native PR monitoring for external waits. Do not recreate polling with sleep loops or a second watcher. Cancel replaced tasks and preserve their useful artifacts.

Autonomy covers the requested work, not unrelated skill rewrites, backlog creation, team-chat reads or messages, first publication, merges or deployments. Stop at a real authorization boundary or concrete blocker. Keep progressing through ordinary implementation choices.

Wayfinder plans work that is too large for one session as a map of decision tickets, and resolves one ticket in each session. Handoff writes the document another agent continues from.

Pausing records what is local, committed or published. It may checkpoint scoped work locally, but must preserve unrelated edits and obey an immediate stop instruction.
