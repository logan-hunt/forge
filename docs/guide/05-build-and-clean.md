# Build and clean

Build the smallest complete change, preserving validation, failure handling, accessibility and the requested behavior. Ponytail is Forge's simplicity lens: Forge's hook reports its level alongside the Forge mode, and the level sets how strictly this guidance applies without changing the mode.

Divide work by ownership and dependencies. Give delegates the goal, allowed paths, relevant sources, chosen mode, proof and publication boundaries. Different writers must not race on shared files. Use the active host's supported isolation and completion lifecycle.

Prefer a lever for repeatable work or difficult proof. Reuse an existing command or harness when it already meets the need. A new script earns its maintenance through deterministic work or verification, not merely because the task is nontrivial.

Review Comments removes narration and stale claims after understanding them. Keep useful constraints and ambiguous warnings until verified. Cleanup must not become an unrequested architectural rewrite.
