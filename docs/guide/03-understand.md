# Understand the work

Use how for the runtime path and ownership. Use why for the forces and historical decisions behind it. Ground evidence in relevant code, commits, tickets and available documentation. Team chat is excluded unless the user explicitly asks to read it.

Total Recall reconstructs bounded prior context. Pin topic, workspace and date window. Preserve source identities, unknown origins and coverage gaps. An assistant's statement is a report, not proof of a user preference. Inspect a named T3 thread before answering about it.

Refine Prompt improves the method and proof without automatically broadening the task. When the question is factual, use a permitted observation to settle it. A plan-only request still does not authorize a prototype or code change.
