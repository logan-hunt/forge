# RESOURCES.md format

`RESOURCES.md` is the curated set of trusted sources for this topic. Take the knowledge for lessons from these sources, not from parametric guesses. Wisdom comes from the communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognized experts, peer-reviewed work, and communities with strong moderation. Leave out marketing that is presented as education.
- **Annotate every entry.** A bare link is useless in three months. Add one line that says what the resource covers and when to use it.
- **Group by Knowledge and Wisdom.** This follows the philosophy in [SKILL.md](../SKILL.md). A resource does not need to appear in both groups.
- **State the gaps.** If no good resource exists for an area the mission needs, list what is missing in a `## Gaps` section. The list directs later searches.
- **Remove weak resources.** Remove a resource that proved wrong, shallow or off-mission. Five sharp sources are better than thirty mediocre ones.
- **Record community preferences.** If the user does not want to join communities, note it here, so that later sessions do not propose them again.
